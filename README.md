# Timeswise 前端

`timeswise` 是“时间序列数据分析助手”的前端仓库，对应当前正式交付的对话式前端界面。

## 项目定位

本项目不是独立于既有产品体系的全新项目，而是基于原有 Web 形态能力演进出的对话式产品前端。

当前正式交付口径下：
- 前端正式仓库：`timeswise`
- 后端正式目录：`timewise-backend/mcp/src`
- 原有业务基础后端：`timewise-backend/app`

## 当前分支

正式交付前端分支：
- `v2`

## 技术栈

- React 18
- TypeScript
- Vite

## 本地启动

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务

```bash
npm run dev
```

默认访问地址：
- `http://localhost:5173`

### 3. 构建验证

```bash
npm run build
```

## 对接说明

当前前端默认对接本地后端：
- `http://localhost:8000`

正式部署前需要根据目标环境调整后端地址，并重新执行前端构建。

## 主要能力

- 上传时间序列数据文件
- 通过自然语言发起分析请求
- 展示分析结果、过程产物与导出内容
- 与 MCP 后端联动完成分析闭环
